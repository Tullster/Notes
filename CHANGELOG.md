# Changelog

## 1.0.0

- Chapters with focus mode, typewriter scrolling, optional typewriter sound, smart quotes, bold and italic shortcuts, and scene breaks.
- Corkboard with flat minimal cards, label colour bars and pins, heading labels, red threads, alignment guides, a selection toolbar, and arrange by grid, label, or type. Search, filter, multi-select, undo, redo, and list view.
- Formatting bar, preview, list and quote continuation, and clean up formatting. Page width and line spacing. Word and print styles: Manuscript or Book.
- Versions with comparison. Find and replace across the book.
- Import from Word, Markdown, or text. Export to Word, Markdown, PDF (print), and JSON backup.
- Sync between devices through a private GitHub Gist. Offline use and installation.
- Keyboard access, screen reader labels, light and dark themes, phone layout.
